# Task 2: Exploratory Data Analysis (EDA)

**Objective:** To explore a dataset using Python, understand its structure, identify patterns and anomalies, and visualize relationships between variables.

**Tools Used:** Python, Pandas, NumPy, Matplotlib, and Seaborn.

**Dataset:** Restaurant Tips Dataset.

**Work Performed:**

1. Loaded and inspected the dataset.
2. Identified variables and their data types.
3. Checked for missing values and duplicate records.
4. Calculated descriptive statistics.
5. Explored average bills and tips across different days.
6. Created visualizations to identify trends and relationships.
7. Examined potential outliers and correlations.

**Conclusion:** Exploratory Data Analysis helped us understand the dataset, summarize important statistics, visualize relationships between variables, and identify potential data quality issues for further analysis.
